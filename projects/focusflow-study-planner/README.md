# FocusFlow — برنامه‌ریز مطالعه

یک برنامه‌ی فارسی و واکنش‌گرا برای مدیریت کارهای روزانه‌ی مطالعه، ساخته‌شده با HTML، CSS و JavaScript خالص.

## امکانات
- افزودن و حذف کارها
- اولویت‌بندی ساده
- علامت‌گذاری کارهای انجام‌شده
- نمایش درصد پیشرفت
- ذخیره‌ی اطلاعات در مرورگر با `localStorage`
- بدون نیاز به نصب یا API

## اجرا
فایل `index.html` را در مرورگر باز کن.

## محدودیت‌ها
اطلاعات فقط در همان مرورگر و دستگاه ذخیره می‌شود؛ نسخه‌ی فعلی حساب کاربری یا همگام‌سازی ابری ندارد.

ساخته‌شده برای تمرین طراحی رابط کاربری، DOM و ذخیره‌سازی محلی در JavaScript.

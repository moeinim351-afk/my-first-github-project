# Pocket+ — ثبت درآمد و هزینه

یک داشبورد فارسی کوچک برای تمرین فرم‌ها، محاسبات و ذخیره‌سازی محلی در JavaScript.

## امکانات
- ثبت درآمد و هزینه
- محاسبه‌ی مانده، درآمد کل و هزینه کل
- فهرست تراکنش‌ها و حذف موردی
- ذخیره‌ی محلی با `localStorage`
- نمایش واکنش‌گرا برای موبایل و دسکتاپ

## اجرا
فایل `index.html` را در مرورگر باز کن.

## حریم خصوصی و محدودیت‌ها
داده‌ها فقط در مرورگر فعلی ذخیره می‌شوند. این پروژه‌ی آموزشی برای اطلاعات حساس مالی یا استفاده‌ی واقعی چندکاربره طراحی نشده است.

# Math Quest — چالش ریاضی

یک آزمون کوتاه و تعاملی ریاضی به زبان فارسی با بازخورد آموزشی پس از هر پاسخ.

## امکانات
- ۵ سؤال چهارگزینه‌ای
- ترتیب تصادفی سؤال‌ها در هر بار شروع
- امتیاز از ۱۰۰
- توضیح کوتاه برای پاسخ هر سؤال
- طراحی واکنش‌گرا و بدون وابستگی خارجی

## اجرا
فایل `index.html` را در مرورگر باز کن.

## نکته آموزشی
این نسخه نمونه‌ی اولیه است و برای ارزیابی رسمی یا نمره‌دهی مدرسه طراحی نشده است. می‌توان بعداً سطح سؤال‌ها، فصل‌ها و بانک سؤال را توسعه داد.
